What it does

  • Clip — cut a segment from a local file or a YouTube link.
  • Download — grab a YouTube video (MP4 or MKV), optionally split by chapter.
  • Mix — join clips with crossfades, lay them out in a grid, or blend them.

On first use the app downloads the video engines it needs (ffmpeg and yt-dlp) automatically — this needs an internet connection once.

Installing

macOS

Open the .dmg and drag Video Tools to Applications. The app isn't signed yet, so the first time: right-click it → Open → Open (a normal double-click will be blocked once).

Windows

Unzip and run video-tools.exe. SmartScreen may warn about an unrecognized app — click More info → Run anyway. The Download tab also needs WSL or Git Bash; Clip and Mix do not.

Linux

Extract the tarball and run ./video-tools, or install it for the app menu:

tar xzf video-tools-1.0.0-linux.tar.gz
cd video-tools-1.0.0-linux
install -Dm755 video-tools ~/.local/bin/video-tools
install -Dm644 video-tools.png ~/.local/share/icons/hicolor/256x256/apps/video-tools.png
install -Dm644 video-tools.desktop ~/.local/share/applications/video-tools.desktop
